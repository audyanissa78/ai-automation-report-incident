# ai-automation-report-incident
Mengembangkan Autonomous Agent menggunakan LangChain dan Llama-3 yang mampu mengambil keputusan real-time berdasarkan laporan teks tidak terstruktur atau laporan dari suara. Sistem otomatis memilah insiden kritis untuk dieskalasi ke manajemen (via Email Simulation)/ (Whatsapp) dan semua hal diarsipkan ke log tanpa campur tangan manusia
